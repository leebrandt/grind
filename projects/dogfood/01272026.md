### Rejecting Ideas

I just added the idea of rejecting an idea. It follows this flow:

```
grind list ideas
```

This will list all the current ideas that have not been rejected.

```
grind reject idea 2
```

Using the number from `grind list ideas` listing, it renames the file for the idea to `rejected-{timestamp}.md`. Then, when listing the ideas, it doesn't list ideas marked as rejected.

**Unless**... You *want* to see all of them. Then you just run the command with `-a|--all` switch:

I sometimes have ideas that I think are good, but I don't want to *do* them; so I want to put them on my ideas page on HiP. For instance: I thought about writing a book about a trans-person who helps an abused woman who hates her. I think that's an outstanding idea, but it should be written by a trans person. So I offer them up as free ideas on my website.

So I would want to list rejected ideas only, to see which might be good ideas that just aren't for me. 
 would run the `list ideas` command with a "-r|--rejected" flag. I don't know why somebody would *want* to type out "rejected". That's just the way all these CLIs work. (I think it's for when they're used programatically. So if I was calling `grind` from a GUI.).

```
grind list ideas -r
```

Finally, if I have "gardened" all the redeemable ideas [*singing Irredeemable from Spririted*], I can clean things up by running `prune ideas`, which will delete the files in the ideas folder that start with 'rejected-'.
