Also implemented the config commands. Now I can run:

```
grind config --list 
```

And see where my current project settings are set. If I am not in a project worktree, it just returns the global values. It also has the ability to change them:

```
grind config billing.defaultRate 120
```

To set the bill rate for the current project or globally, if you're not in a project worktree when you run it. If you *are* in a project workspace and you still want to set the global bill rate and not the project-level value, you can just add the -g flag.
