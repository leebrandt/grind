# Neck Ranger... Out!

Over NYE, I thought I'd resurrect an old Debian laptop with Arch Linux. I got sucked into the rabbit hole of the Linux Minimalist Dev Setup (that's what I'm calling it). It's Arch Linux+Omarchy, basically (I built it myself before I found out about Omarchy *shudders*). 

Linux Ricing, the kids are calling it. 

I LOVE the workflow. It's immersive. 

I still suck pretty bad at Vim, but LazyVim carries a lot of that weight. But I am getting to the point where my coding in LazyVim is almost as fast as coding in VS Code. And I can always choose `code project` over `nvim project` any time I just need to git 'er DUN.

The tiling window manager saves me a ton of time rearranging my windows all the time. That's how I like my windows, already. One key-chord away. Plus, it means I don't have to learn tmux... yet.

I'm still new to all of it, but an old hat at using Linux. If you're into it, drop me some /unixporn in the comments.

Neck Ranger... out :D
