### What I like so far...

I like that I'm living in that root directory, pretty much. Run `grind work project` and *whoosh*, I'm in NVIM in that project. Basically NVIM open in that directory. Then exit and *whoosh* I'm back in the root. Of course, I never left it, I just opened that folder in NVIM. I could do it ll by hand. ALL of this stuff I could do by hand. But it would be harder. Several commands, remembering paths (not as bad with intellisense in the terminal).

I also love that I can stay in the terminal. It makes me feel smart. Like that dude I saw in the "server room" back in 1997, throwing commands at his Linux server in the rack behind me. I wanted to be that keyboard cowboy. That feeling is calling to me again. I'm having a blast feeling like a 1337 H4x0r from the command line. More pragmatically, it will allow me to rid myself of the big corporate software. Find me a decent laptop (Framework or System 76), throw Linux on it, and live my life there. Writing code, writing books/stories, writing songs, and writing video scripts. Basically a ton of writing. But I love it.

I LOVE LazyVIM! It allows me to be... fucking LAZY! I don't have to learn all the vim motions at once. I already know SOME vim commands. Just from using it with Git. I just had to break myself of the `:wq` motion. Most of the time, I just want to save. Luckily, LazyVIM's got the ctrl+s keychord for that. Plus: it *also* makes me feel fucking smart.

Working from the root means I don't have to implement some features. I have `grind list ideas`, right? But I don't need `grind list projects`, I can just use `ll` for that. It's a oh-my-zsh shortcut I have set to `eza -lah`, which just lists all the top-level folders there. The .git.grind.git repo is a bare repo, so you won't see it in the listing. The only thing that is NOT a project is the `grind` folder itself. So just running `ll` from the root will give me a good visual if I am taking on too many projects. Eventually, I'll add some WIP limit config settings. So I can set my WIP limit to 5, and if I try to take on more than that, I'll add my 'Samuel L. Jackson Error Handler' to say, "Finish something *first*, motherfucker!"

But I think about what the workflow would feel like that way. Actually, okay fuck it. Let's do it right here. That's what this is *for* right?

as opposed to now:
